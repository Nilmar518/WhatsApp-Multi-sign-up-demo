Pregunta 5: ¿Cómo se organiza el canvas del builder?

Esto define cómo el usuario arrastra y acomoda los campos. Cada enfoque tiene distinto nivel de libertad vs. simplicidad.

A — Filas con columnas (recomendado)

El documento se divide en filas. Cada fila puede tener 1, 2 o 3 campos lado a lado. Las filas se reordenan arrastrando. Genera PDFs limpios y predecibles.

— CANVAS LIBRE —
📋 NOMBRES
📅 FECHA

#️⃣ N°
✍ FIRMA

B — Canvas libre (arrastrar a posición exacta)

El usuario posiciona cada campo libremente como si fuera Figma. Máxima flexibilidad, pero más complejo de implementar y difícil de exportar a PDF limpio.

C — Secciones agrupadas con grilla interna

El documento tiene secciones colapsables (Datos del huésped, Pago, etc.). Dentro de cada sección se acomodan campos en grilla. Secciones y campos se reordenan por separado.
